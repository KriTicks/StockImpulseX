## ✨ Основные возможности

*   **🚦 Контроль сроков**: Автоматическая подсветка товаров.
    *   🟤 **Тёмно-красный** — товар просрочен
    *   🔴 **Красный** — 1–3 дня до окончания срока (критично)
    *   🟠 **Оранжевый** — 4–7 дней (внимание)
    *   ⚪ **Белый** — срок в норме (>7 дней)
*   **🗂️ Разделение учёта**: Ведите отдельно складские запасы и товары в торговом зале.
*   **🔍 Умный поиск и фильтрация**: Быстро находите нужные позиции по названию, категории или ID.
*   **📄 Экспорт в CSV**: Выгружайте данные в Excel для анализа и отчетности.
*   **⏳ Автообновление**: Данные обновляются каждые 5 минут, не нужно перезапускать программу.

## 🚀 Быстрый старт

Просто скачайте последнюю версию и запустите `.exe` файл.

1.  Перейдите в раздел **[Releases](https://github.com/KriTicks/StockImpulseX/releases)**.
2.  Скачайте архив `StockImpulseX_v1.0.zip`.
3.  Распакуйте в любую папку.
4.  Запустите `StockImpulseX.exe`.

> База данных создастся автоматически при первом запуске рядом с программой.

## 🛠️ Стек технологий

Проект написан с использованием современных и надёжных технологий:

*   **Платформа**: .NET 8.0
*   **Интерфейс**: Windows Presentation Foundation (WPF)
*   **База данных**: SQLite (легковесная, не требует установки)
*   **Архитектура**: MVVM
